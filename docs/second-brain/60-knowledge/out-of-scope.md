# Out of Agent write scope

The objects below exist in Workspace. An Agent locates them only when the owner asked to read.

## Resource

See `resources.md`. Create or refile a Resource only when the owner asked in the current turn.

## Archives

Archives are owner-manual. Catalog `Name` `Archives` holds inactive material. Catalog `Name` `Historical Archives` holds old finance rows. Archives is not a data source.

## Allocation

Allocation appears in the Financial Database Manual as a locked-cash state. Allocation is not implemented. Treat Allocation as redundant.

## TOP OF MIND

Area `TOP OF MIND` and the `Tasks & Action View` section titled `Today + Top Of Mind` are owner-manual. An Agent MUST NOT assign either.

## Articles and CS Topics

See `../70-extras/articles.md` and `../70-extras/cs-topics.md`. Articles is a specialist notebook. CS Topics is not Knowledge Base Topics.

## Fear Setting Database

See `../70-extras/fear-setting.md`. Fear Setting Database is owner-manual.
