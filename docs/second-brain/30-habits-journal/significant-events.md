# My Significant Events

My Significant Events is a yearly event with Outcome and Lessons. Assignment of Top 20 stays with the owner unless the owner asked to set it.

## Locate

| Item              | Value                                                       |
| ----------------- | ----------------------------------------------------------- |
| Data source title | My Significant Events                                       |
| Data source ID    | see `../03-identifiers.md`                                  |
| Database page     | `https://app.notion.com/p/316919d4193681e09baaea9a895fd026` |
| Title property    | `Event`                                                     |

## Writable properties an Agent may set

| Property       | Type     | Fill rule                                |
| -------------- | -------- | ---------------------------------------- |
| `Event`        | title    | Event name.                              |
| `Outcome`      | select   | `Win` or `Loss`.                         |
| `Lessons`      | text     | Owner language.                          |
| `Related Year` | relation | Limit 1. Matching Years page.            |
| `Related Area` | relation | Optional. Do not set Area `TOP OF MIND`. |
| `Top 20`       | checkbox | Set only when the owner asked.           |
