# Jars

Jar is the highest aggregation of spending philosophy. Financial Category belongs to Jar. Jar MUST NOT hold a transaction.

## Locate

| Item              | Value                                                       |
| ----------------- | ----------------------------------------------------------- |
| Data source title | Jars                                                        |
| Data source ID    | see `../03-identifiers.md`                                  |
| Database page     | `https://app.notion.com/p/31c919d4193680de87f1fa4f04d7366e` |
| Surface           | Catalog `Name` `The 6-Jar System and Categories`            |
| Title property    | `Jar Title`                                                 |

Live `Jar Title` values are Necessities, Entertainment, Long-Term, Education, Financial Freedom, Give, Debt.

Jar `Debt` is leftover bad debt under dedicated handling. Jar `Debt` is not a seventh jar of the 6 Jars method.

## Writable properties an Agent may set

| Property              | Type     | Fill rule                                                                    |
| --------------------- | -------- | ---------------------------------------------------------------------------- |
| `Jar Title`           | title    | Do not invent a new Jar unless the owner asked.                              |
| `Related Category`    | relation | Financial Category pages that roll up into the Jar.                          |
| `LTD Meta Start Date` | date     | Lifetime to date start. Copy an existing Jar when the owner did not specify. |

## Do not write

Formula and rollup properties such as `LTD Expense` or `Jar Report`.
