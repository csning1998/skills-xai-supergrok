# Finance

Daily bookkeeping is the second active loop. The Financial Database Manual splits finance into four collections that do not overlap.

1. Dimension holds Jar and Financial Category.
2. Period holds Fiscal Years and Monthly Budget.
3. Ledger holds Income Event, Fixed Expenditure, and Flexible Expenditure.
4. Auxiliary on paper holds Wish List. Allocation is unused.

Jar MUST NOT hold a transaction. Flexible Expenditure MUST set exactly one Financial Category. Every ledger event MUST belong to exactly one Monthly Budget. Wish List and ledger events are disjoint.

Currency display on number properties is New Taiwan Dollar.

Open surfaces from Catalog `Name` `Financial Dashboards`, `Financial Inbox`, `The 6-Jar System and Categories`, `Monthly Flexible Budgets`, `Fixed Expenditures`, and `Financial Year Overview`.

One locate and fill file exists for each finance H3. Allocation has no file.
