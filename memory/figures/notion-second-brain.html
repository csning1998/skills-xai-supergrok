核心資料庫關係

Areas 是 PARA 的穩定橫切軸。Goals 帶時間視野。Projects 有盡頭。Tasks 是可執行下一步。Notes 在 Topics 與 Notebooks 之間雙向連結。

  • Content Creation
  • Environment: House and Room
  • Family and Social
  • Finances
  • Fun and Hobbies
  • Personal Development
  • Physical Health and Fitness
  • Miscellaneous
  • TOP OF MIND

執行鏈

  • Goal 來自 Covey 七個習慣的目標定義
  • Task 必連 Goal，不必連 Project
  • Project 是相似任務的 WBS 或集合
  • Resources 與 Archives 預設不管
  • TOP OF MIND 只由使用者手動設定

知識鏈

  • Notes 連到 Notes、Topics、Notebooks、Resources、Journal
  • Note Type 使用 Literature 與 Permanent 等卡片盒狀態
  • Resources 是 PARA 的參考庫
  • Archives 收已停用項目

財務四層

Financial Database Manual 的 MECE 切法。Jars 不承載交易。每筆支出只歸一個 Category。每筆事件只歸一個 Monthly Budget。

Dimension

  • Jars
  • Financial Categories

Period

  • Fiscal Years
  • Monthly Budgets

Ledger events

  • Income
  • Fixed Expenditure
  • Flexible Expenditure 與 logs

Auxiliary

  • Wish List（意圖，不是帳）
  • Allocation 未實作，視為多餘，先放著

Jars

Necessities, Entertainment, Long-Term, Education, Financial Freedom, Give。Debt 是以前留下的爛帳專項，不是六罐子方法裡的第七罐。

固定支出經 Subscriptions 或 Installments 產生 Fixed Expenditure。彈性支出只連一個 Category，再往上彙總到 Jar。
